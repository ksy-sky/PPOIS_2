# Шашки (Checkers) - Игровое приложение на Pygame

## Описание проекта

Классическая игра **Шашки (Checkers)** с графическим интерфейсом на Pygame. Реализована полная логика игры, анимации, звуковое сопровождение, таблица рекордов и **онлайн-режим** для игры по сети.

Проект разработан в рамках изучения событийно-ориентированного программирования на Python с использованием библиотеки Pygame.

## Основные возможности

- **Два режима игры:**
  - **Локальный режим** - игра на двоих за одним компьютером (доска переворачивается после каждого хода)
  - **Онлайн режим** - игра по сети через сервер (один игрок видит доску перевёрнутой)

- **Полная логика шашек:**
  - Ходы по диагонали на одну клетку вперёд
  - Обязательные взятия шашек соперника
  - Превращение простых шашек в дамки
  - Дамка ходит на любое количество клеток по диагонали
  - Последовательные взятия за один ход
  - Автоматическое определение победителя

- **Анимации:**
  - Плавное перемещение шашек по доске
  - Анимация исчезновения (сжатие + прозрачность)
  - Анимация полёта шашки при взятии (вращение + след)

- **Звуковое сопровождение:**
  - Фоновая музыка
  - Звуки клика, хода и взятия
  - Регулировка громкости через конфигурацию

- **Таблица рекордов:**
  - Сохранение лучшего результата
  - Ввод имени при установке рекорда
  - Хранение в YAML-файле

## Управление

| Действие | Управление |
|----------|-----------|
| Выбор пункта меню | Стрелки ↑/↓ + Enter |
| Выбор шашки | Клик левой кнопкой мыши |
| Ход шашкой | Клик на целевой клетке |
| Выход в меню | `ESC` |
| Ввод имени при рекорде | Клавиатура + Enter |

## Правила игры

1. **Ходы:** Простые шашки ходят на одну клетку вперёд по диагонали
2. **Взятия:** Если есть возможность взять шашку соперника - это обязательно!
3. **Дамка:** При достижении последней горизонтали шашка превращается в дамку
4. **Дамка ходит:** На любое количество клеток по диагонали
5. **Победа:** Игрок проигрывает, если у него не осталось ходов или шашек

## Конфигурация

Все настройки хранятся во внешних YAML-файлах:

### configs/settings.yaml
```yaml
screen:
  width: 800
  height: 800
fps: 60
sound:
  music_volume: 0.3
  effects_volume: 0.5
paths:
  music: "assets/sounds/background.mp3"
  click_sound: "assets/sounds/click.wav"
```

### configs/game_config.yaml
```yaml
board:
  size: 8
  cell_size: 80
colors:
  light_cell: "#f0d9b5"
  dark_cell: "#b58863"
  highlight: "#ffff00"
  possible_move: "#00ff00"
```

## 🌐 Онлайн-режим

Для игры по сети необходимо:

1. Запустить сервер: `python server.py`
2. Запустить два клиента: `python main.py` (в разных окнах)
3. Оба клиента выбирают "Онлайн игра"
4. Сервер раздаёт цвета (белый/чёрный)
5. Игрок за чёрных видит доску перевёрнутой

**Технические детали:**
- Протокол: TCP
- Порт: 5555
- Формат сообщений: JSON с разделителем `\n`
- Хост: localhost (можно изменить в коде)
